# English Reps

簡單的多益單字練習網站，完整收錄使用者提供的《【刷刷鍋】多益一千單字表》100 頁、1,000 筆單字。使用原表的順序、詞性、中文解釋、中英例句；每筆資料附有來源頁碼，分成 20 個單元，每單元 50 字。

## 功能

- 單字卡：先回想、再查看解釋及例句，以「記住了／還不熟」記錄學習狀態。
- 選擇測驗：每次最多 10 題，選項去除相同中文答案，答題後顯示解析；結果頁可重練這次不熟的字。
- 單元篩選、只練不熟的字、隨機換一組、瀏覽器英文發音。
- 單字庫：英文／中文搜尋、單元／詞性篩選、分頁、中英例句、待複習標記。
- 瀏覽器本機保存掌握度、待複習清單及測驗正確率；儲存不可用時顯示提示，仍可繼續練習。
- 手機與桌面版、鍵盤操作、焦點提示、減少動態效果偏好、載入失敗重試。

這個版本不需要後端、帳號或外部服務。學習進度只存在目前的瀏覽器，不會跨裝置同步；清除網站資料會移除進度。發音使用瀏覽器與作業系統的語音功能，實際支援依裝置而異。各筆單字及其不同詞性均依原表保留。

## 本機執行

需要 Node.js 22 以上，無需安裝套件。

```sh
npm run dev
```

開啟 `http://localhost:5173`。可用 `PORT=8080 npm run dev` 或 `npm run dev -- --host 127.0.0.1 --port 8080` 指定監聽位址與埠號。

```sh
npm run check
npm test
```

測試涵蓋 1,000 筆資料完整性、PDF 跨行還原、每字唯一答案、搜尋篩選、錯題複習、進度計算及損壞儲存資料的處理。

## 資料與部署

`public/` 是完整的靜態網站，可直接交由靜態網站伺服器提供；沒有建置步驟。開發伺服器僅提供 `public/` 的內容。

單字資料位於 `public/data/vocabulary.json`。如需由原始 PDF 重新匯入，使用 Poppler 與 Python 3：

```sh
pdftotext -layout '/path/to/source.pdf' /tmp/vocabulary.txt
python scripts/import-vocabulary.py /tmp/vocabulary.txt public/data/vocabulary.json
```

匯入器驗證每頁 10 筆、共 1,000 筆，還原跨行解釋及英文例句中的斷字。PDF 內容只作為詞彙資料使用，未納入執行指令；原始 PDF 未提交至 repo。

開發變更以功能分支送至 `develop`；`master` 保留正式版本用途。
