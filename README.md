# English Reps

多益單字與聽力練習網站，完整收錄使用者提供的《【刷刷鍋】多益一千單字表》100 頁、1,000 筆單字。使用原表的順序、詞性、中文解釋、中英例句；每筆資料附有來源頁碼，分成 20 個單元，每單元 50 字。另提供 30 道原創 Part 2 風格應答練習。

## 功能

- 單字卡：先回想、再查看解釋及例句，以「記住了／還不熟」記錄學習狀態。
- 選擇測驗：每次最多 10 題，選項去除相同中文答案，答題後顯示解析；結果頁可重練這次不熟的字。
- 單元篩選、只練不熟的字、隨機換一組、瀏覽器英文發音。
- 單字庫：英文／中文搜尋、單元／詞性篩選、分頁、中英例句、待複習標記。
- 瀏覽器本機保存掌握度、待複習清單及測驗正確率；儲存不可用時顯示提示，仍可繼續練習。
- 手機與桌面版、鍵盤操作、焦點提示、減少動態效果偏好、載入失敗重試。

## 聽力練習

- 30 題自編應答題：職場會議、交通旅行、顧客服務各 10 題，非 ETS 官方試題，沒有使用第三方題目或錄音。
- 每組最多 10 題，按下播放後朗讀英文問句與 A／B／C 三個回答；完整播放一次後才可作答，作答前不顯示逐字稿或答案。
- 提供 0.8×、1×、1.15× 語速、重播及停止；切頁、切題、變更語速或隱藏頁面會停止語音。
- 作答後顯示中英逐字稿、正確答案、解析與重點單字；結果頁可重練本次錯題，也能按主題只練累積錯題。
- 聽力正確率、累計作答和待複習清單使用獨立的 `english-reps.listening.v1` localStorage 紀錄，不影響原有單字進度。

語音使用 Web Speech API 與裝置的英語合成語音，不需外部語音 API 金鑰或後端。音色依瀏覽器與作業系統而異；需要支援 `speechSynthesis` 與可用的英語語音。播放失敗或不受支援時會顯示提示，且不會將中斷或失敗的播放當成完成。練習時請確認裝置音量與英語語音設定。

題庫在 `public/data/listening.json`，每題包含主題、英文問句、中譯、三個雙語回答、正解、解析及重點單字。這是自學練習；題庫與答案會下載至前端，未作為正式測驗的保密題庫。

這個版本不需要後端、帳號或外部服務。學習進度只存在目前的瀏覽器，不會跨裝置同步；清除網站資料會移除進度。發音使用瀏覽器與作業系統的語音功能，實際支援依裝置而異。各筆單字及其不同詞性均依原表保留。

## 本機執行

需要 Node.js 22 以上；執行網站本身無需安裝套件。

```sh
npm run dev
```

開啟 `http://localhost:5173`。可用 `PORT=8080 npm run dev` 或 `npm run dev -- --host 127.0.0.1 --port 8080` 指定監聽位址與埠號。

```sh
npm ci
npm run check
npm test
```

`npm ci` 僅安裝介面互動測試使用的開發依賴 Happy DOM，網站執行時沒有第三方套件。互動測試在模擬 DOM 與語音事件中執行，涵蓋作答前隱藏答案、播放門檻、取消播放、整組練習、錯題重練、進度讀取、載入重試及原網站導覽整合。

測試涵蓋 1,000 筆單字完整性、PDF 跨行還原、每字唯一答案、搜尋篩選、錯題複習、進度計算、30 題聽力資料驗證、題目篩選與計分、兩種進度分離，以及語音完成／取消／錯誤／逾時的處理。語音測試透過可注入的引擎事件驗證狀態，不代表所有真實裝置的語音音質皆已驗證。

## 資料與部署

`public/` 是完整的靜態網站，可直接交由靜態網站伺服器提供；沒有建置步驟。開發伺服器僅提供 `public/` 的內容。

單字資料位於 `public/data/vocabulary.json`。如需由原始 PDF 重新匯入，使用 Poppler 與 Python 3：

```sh
pdftotext -layout '/path/to/source.pdf' /tmp/vocabulary.txt
python scripts/import-vocabulary.py /tmp/vocabulary.txt public/data/vocabulary.json
```

匯入器驗證每頁 10 筆、共 1,000 筆，還原跨行解釋及英文例句中的斷字。PDF 內容只作為詞彙資料使用，未納入執行指令；原始 PDF 未提交至 repo。

開發變更以功能分支送至 `develop`；`master` 保留正式版本用途。
